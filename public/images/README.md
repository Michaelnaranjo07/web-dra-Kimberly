# Fotografía del consultorio

Reemplazar las URLs de Unsplash en el CMS/defaults por archivos locales aquí.

## Tomas recomendadas (E-E-A-T)

1. `dra-kimberly.jpg` — retrato profesional de la Dra. Kimberly
2. `consultorio-hero.jpg` — consultorio (hero)
3. `consultorio-detalle.jpg` — detalle clínico / sillón
4. `pacientes/` — solo con consentimiento informado firmado

Hasta tener fotos reales, el sitio puede seguir usando stock; no publicar campaña fuerte de ads/salud sin fotos propias.
